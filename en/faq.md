# FAQ

Here are frequently asked questions and answers from users.

## General Questions

### Q: What permissions does the app need?

**A**: The app requires:
- **Network permission**: For searching and connecting to devices
- **Storage permission**: For accessing phone gallery and video library
- **Location permission** (Android): Some Android versions require location permission to scan Wi-Fi devices

### Q: Why can't I find my device?

**A**: Please check:
1. **Network connection**: Make sure phone and target device (TV/PC) are on the **same Wi-Fi network**
2. **Device status**: Make sure target device is on and running properly
3. **App status**: For remote features, make sure MarmotX app is installed and running on target device
4. **Firewall**: Check PC firewall settings to ensure MarmotX can communicate
5. **Refresh search**: Tap refresh button to search again

### Q: Can't control after connecting?

**A**: Try:
1. Check network connection stability
2. Reconnect to device
3. Restart the app
4. Restart MarmotX app on target device (for remote features)

## Casting Issues

### Q: Photo/Video casting failed?

**A**: Please check:
1. Phone and TV are on the same Wi-Fi network
2. TV supports DLNA
3. DLNA service is enabled on TV
4. Try restarting TV and phone
5. See [Troubleshooting](troubleshooting.md) for more help

### Q: Video is laggy when casting?

**A**: Lag may be due to network issues:
1. Check Wi-Fi signal strength
2. Move phone and TV closer to router
3. Turn off other devices using the network
4. Try lower video resolution (if supported)

### Q: What video formats are supported?

**A**: Common formats like MP4, AVI, MOV are supported. If a format is not supported, please convert it first.

## Remote Control Issues

### Q: How to install MarmotX?

**A**: 
- **TV**: Search "MarmotX" in TV app store and install
- **PC**: Download MarmotX PC installer from official website and install

### Q: MarmotX won't start?

**A**: Please check:
1. Device system version meets requirements
2. Enough storage space available
3. Try reinstalling MarmotX
4. Check MarmotX log files (if available)

### Q: High control latency?

**A**: Latency may be due to network issues:
1. Make sure phone and target device are on the same Wi-Fi network
2. Check Wi-Fi signal strength
3. Turn off other devices using the network
4. For PC, try using wired network connection

## Network Issues

### Q: Must I use Wi-Fi?

**A**: Yes, all features require phone and target device to be on the same Wi-Fi network. Mobile data is not supported.

### Q: Can I use hotspot?

**A**: In theory yes, but it may be unstable. We recommend using Wi-Fi from a router.

### Q: Can I use different Wi-Fi bands?

**A**: As long as phone and target device are on the same Wi-Fi network (even different bands like 2.4GHz and 5GHz), it usually works fine.

## Other Questions

### Q: What devices are supported?

**A**: 
- **Phone**: Android and iOS
- **TV**: Smart TVs with DLNA support (for casting) and smart TVs with MarmotX installed (for remote)
- **PC**: Windows, macOS, and Linux with MarmotX installed

### Q: Is the app free?

**A**: Yes, the app is completely free to use.

### Q: How to report issues?

**A**: If you encounter issues:
1. Check [Troubleshooting](troubleshooting.md)
2. Use in-app feedback feature
3. Contact our technical support
