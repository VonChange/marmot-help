# Troubleshooting

If you encounter issues, please follow these steps to troubleshoot.

## Cannot Find Device

### Symptoms
App cannot find target device (TV or PC).

### Steps

1. **Check Network Connection**
   - Confirm phone and target device are on the **same Wi-Fi network**
   - Check Wi-Fi names match
   - Try disconnecting and reconnecting Wi-Fi

2. **Check Device Status**
   - Confirm target device is on and running properly
   - For casting: Confirm TV supports DLNA and DLNA service is enabled
   - For remote: Confirm MarmotX app is installed and running on target device

3. **Refresh Search**
   - Tap refresh button in app to search again
   - Wait a few seconds for search to complete

4. **Restart Devices**
   - Restart phone
   - Restart target device
   - Restart router (if other methods fail)

5. **Check Firewall**
   - For PC remote: Check PC firewall settings to ensure MarmotX can communicate
   - Temporarily disable firewall to test (remember to re-enable after testing)

## Connection Failed

### Symptoms
Device found but cannot connect.

### Steps

1. **Check Network Stability**
   - Ensure Wi-Fi signal is strong
   - Try moving closer to router
   - Turn off other devices using the network

2. **Reconnect**
   - Disconnect current connection
   - Re-select device and connect

3. **Restart App**
   - Completely close the app
   - Reopen the app
   - Try connecting again

4. **Check MarmotX (Remote Features)**
   - Confirm MarmotX app is running
   - Try restarting MarmotX app
   - Check MarmotX logs (if available)

## Casting Failed

### Symptoms
Cannot cast photos/videos to TV after selection.

### Steps

1. **Check DLNA Settings**
   - Confirm TV supports DLNA
   - Confirm DLNA service is enabled on TV
   - Check DLNA options in TV settings

2. **Check File Format**
   - Confirm photo/video format is supported
   - Try testing with other files

3. **Check Network**
   - Ensure network connection is stable
   - Check Wi-Fi signal strength

4. **Restart Devices**
   - Restart phone
   - Restart TV

## Control Not Responding

### Symptoms
Device connected but phone control has no response.

### Steps

1. **Check Connection Status**
   - Confirm device is still connected
   - Check connection status indicator in app

2. **Reconnect**
   - Disconnect
   - Reconnect to device

3. **Check MarmotX (Remote Features)**
   - Confirm MarmotX app is running
   - Try restarting MarmotX app
   - Check MarmotX logs

4. **Check Network**
   - Ensure network connection is stable
   - Check for network latency

## Video Playback Lag

### Symptoms
Video casting is laggy or not smooth.

### Steps

1. **Check Network Speed**
   - Test Wi-Fi speed
   - Ensure network speed is sufficient for video streaming

2. **Optimize Network Environment**
   - Move closer to router
   - Turn off other devices using the network
   - Use 5GHz Wi-Fi (if supported)

3. **Lower Video Quality**
   - Try lower video resolution if supported
   - Test with lower bitrate video files

4. **Check Device Performance**
   - Confirm phone and TV have sufficient performance
   - Close other resource-intensive apps

## App Crashes

### Symptoms
App crashes or force closes during use.

### Steps

1. **Update App**
   - Check for app updates
   - Update to latest version

2. **Clear Cache**
   - Clear app cache
   - Reopen the app

3. **Reinstall**
   - Uninstall app
   - Reinstall latest version

4. **Check Device**
   - Confirm device system version meets requirements
   - Check device storage space is sufficient

## Permission Issues

### Symptoms
App prompts for certain permissions.

### Steps

1. **Grant Permissions**
   - Grant required permissions in system settings
   - Reopen the app

2. **Check Permission Settings**
   - Android: Settings → Apps → Marmot TV Assistant → Permissions
   - iOS: Settings → Privacy → Select permission type

## Still Can't Solve?

If the above methods don't solve your issue:

1. **Collect Information**
   - Record specific steps when issue occurred
   - Record error messages (if any)
   - Record device model and system version

2. **Contact Support**
   - Use in-app feedback feature
   - Provide detailed problem description and collected information

3. **Check Updates**
   - Watch for app updates, new versions may have fixed related issues
