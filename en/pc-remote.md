# PC Remote User Guide

Control your computer with your phone, quick and convenient.

## Preparation

### 1. Install MarmotX (PC)

**MarmotX** must be installed on your computer to use the remote control feature.

**Installation**:
1. Download MarmotX PC installer
2. Install and launch MarmotX app
3. Make sure MarmotX app is running

### 2. Ensure Device Connection

- ✅ Phone and PC are connected to the **same Wi-Fi network**
- ✅ MarmotX app is running on PC
- ✅ Phone and PC are on the same local network

### 3. Open PC Remote

Tap the **PC Remote** button on the app home page to enter the PC remote page.

## Usage Steps

### Step 1: Connect to Device

The app will automatically search for nearby PCs with MarmotX installed. Select your PC from the device list.

**Tips**:
- If you can't see your device, check if MarmotX is running
- Make sure phone and PC are on the same Wi-Fi network
- Tap the refresh button to search again

### Step 2: Start Controlling

Once connected, you can start controlling your PC with your phone.

## Control Features

### 🖱️ Mouse Control

- **Move Mouse**: Slide finger on screen to move mouse
- **Click**: Tap screen to click
- **Right Click**: Long press screen for right click
- **Scroll**: Two-finger swipe up/down to scroll

### ⌨️ Keyboard Input

- **Text Input**: Use phone keyboard to type text
- **Shortcuts**: Support common keyboard shortcuts

### 🌐 Browser Control

- **Open Webpage**: Quickly open common websites
- **Bookmarks**: View and manage browser bookmarks
- **History**: View browsing history

### 📺 Video Playback

- **Video Search**: Search and play videos
- **Playback Control**: Control play, pause, progress, etc.
- **Fullscreen**: One-tap fullscreen video playback

## FAQ

### Q: Can't find device?

**A**: Please check:
1. MarmotX app is installed and running on PC
2. Phone and PC are on the same Wi-Fi network
3. MarmotX app is running properly
4. Check firewall settings to ensure MarmotX can communicate
5. Tap refresh button to search again

### Q: Connection failed?

**A**: Try:
1. Check network connection stability
2. Check firewall settings
3. Restart MarmotX app
4. Restart phone and PC
5. See [Troubleshooting](troubleshooting.md) for more help

### Q: High latency?

**A**: High latency may be due to network issues. Try:
1. Make sure phone and PC are on the same Wi-Fi network
2. Check Wi-Fi signal strength
3. Turn off other devices using the network
4. Try using wired network for PC

### Q: Which operating systems are supported?

**A**: MarmotX supports Windows, macOS, and Linux.
