## 准备条件

### ⚠️ 重要：确保设备在同一 Wi-Fi 网络

**所有功能都需要手机与电视/电脑连接到同一个 Wi-Fi 网络！**

检查方法：
- **手机**：设置 → Wi-Fi，查看当前连接的网络名称
- **电视**：设置 → 网络，查看连接的网络名称
- **电脑**：查看任务栏网络图标，确认连接的网络名称

> 💡 提示：如果网络名称不一致，请先调整到同一网络再使用。

## 📺 电视遥控

### 准备工作

1. **开启电视端 ADB 调试**
   
   电视遥控功能需要电视开启 ADB 调试权限。不同品牌电视开启方式不同，请参考 [如何开启 ADB 调试](adb.md)。

2. **确保同一 Wi-Fi**
   
   手机和电视必须连接同一个 Wi-Fi 网络。

### 使用方法

电视遥控页**只有一个入口**：点击右上角 **「设备」** ![发现按钮](../image/fx.jpg)。应用会**同时搜索局域网内的电视**，已装好服务的和首次需要配对的，都会显示在同一个列表里，不用分开找。

**首次连接（仅需一次）**

1. 打开土拨鼠电视助手，点击「电视遥控」
2. 点击右上角 **「设备」**，稍等片刻，电视会自动出现在列表中
3. 若电视提示 **「安装服务」**，点击后电视端会弹出授权确认，选择「允许」
4. 授权成功后会自动安装电视端组件；**安装完成后**电视会出现在列表上方，再次点击即可连接

**日常使用**

1. 打开土拨鼠电视助手，点击「电视遥控」
2. 点击右上角 **「设备」**，在列表中选择您的电视
3. 连接成功后即可使用飞鼠、触控遥控

> 💡 一台电视仅需授权安装一次。若列表里电视提示服务异常，点击 **「修复」** 即可。搜不到电视时，可在列表底部手动输入 IP 连接。

### 功能特色

- 🖱️ **飞鼠遥控**：手指滑动控制光标，**支持触控操作**，滑动、点击、长按如手机般自然流畅
- ⌨️ **键盘输入**：搜索时直接用手机键盘输入，告别遥控器
- 📱 **应用管理**：安装、卸载、冻结电视应用
- 📺 **电视直播**：内置直播源，轻松看电视

## 💻 电脑遥控

### 准备工作

1. **下载电脑端软件**
   
   前往官网下载对应系统版本：
   - Windows 版：适用于 Windows 10/11
   - Mac 版：适用于 macOS 10.15+
   
   > 下载地址：[官网下载页面](https://www.vonchange.com)

2. **安装并运行电脑端**
   
   安装完成后启动软件，确保软件在后台运行。

3. **确保同一 Wi-Fi**
   
   手机和电脑必须连接同一个 Wi-Fi 网络。

### 使用方法

1. 打开土拨鼠电视助手
2. 点击「电脑遥控」
3. 点击右上角的 **发现按钮** 🔍
4. 应用会自动发现局域网内运行中的电脑端
5. 选择您的电脑，即可开始控制

### 功能特色

- 🖱️ **触控板**：手机变身无线鼠标，躺沙发也能操控
- ⌨️ **键盘输入**：手机键盘直接输入
- 📺 **影视资源**：浏览器投屏观看视频
